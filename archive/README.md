# archive/ —— 早期探索脚本

本目录保存赛题攻关**早期阶段**的探索性脚本，用于记录思路演进过程。

⚠️ **注意：这些脚本已被 `src/` 下的最终方法取代，不作为推荐实现使用。**

## 背景

攻关初期曾尝试用「线性壳结构模型」直接拟合高轮次相关性平台值
（`computecor_hull_v2.py` ~ `computecor_hull_v5.py`），思路是：

- 观察 `Lᵀ` 将单个 nibble 扩散到多个 nibble 的结构特性；
- 依据输入/输出掩码的 `Lᵀ` 图像重叠度估计轨迹束的紧凑程度，从而给出平台值。

早期自评结果（78 有效 / 917.97 分）即基于此模型。

## 为何被取代

该模型本质上是在**对 `V_T` 做反向拟合**，而非正向的 LAT + 堆积引理估计，
既不符合"方式 2 必须基于逼近算法"的精神，精度也不足。

最终改用 `src/method2_v2plus.py` 的**逐轮 S 盒逼近 + 组合枚举**方法，
结果从 78 有效提升至 **318 有效 / 2996.53 分**，且全程只使用 LAT 结构常数。

| `compute_c5.py` / `test_c3.py` | 特定轮次相关性的试探计算 |
| `quick_analysis.py` | 快速统计分析 |
| `test_trail_accuracy.py` / `test_trail_v2.py` | 线性路线精度测试 |
| `run_v5_batch.py` / `gen_v5_input.py` | v5 模型的批量运行与输入生成 |

保留这些内容是为了完整呈现技术路线的试错过程 —— 包括那些**走不通**的方向。
